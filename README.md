# Лабораторная работа №2: Циклы с предусловием и постусловием

## Автор

Чеботников А.В. (Вариант 33)

## Цель

Изучение циклов с предусловием `while` и постусловием `do while` в C++ на примере расчёта атмосферного давления и плотности воздуха на различных высотах.

## Описание

Программа рассчитывает атмосферное давление и плотность воздуха в зависимости от высоты.

Вычисляются:
- Атмосферное давление p.
- Плотность воздуха ρ.

Для расчётов используются формулы:

- `p = p0 * exp(-M * g * h / (R * T))`
- `rho = M * p / (R * T)`

Расчёты выполняются с помощью двух циклов:

- `do while` — для первого диапазона высот с шагом 100 м.
- `while` — для второго диапазона высот с шагом 500 м.

Начальная высота вводится перед каждым циклом. На каждой итерации программа вычисляет давление и плотность, выводит результаты и увеличивает высоту на соответствующий шаг.

## Исходные данные

Для проверки программы используются следующие значения:

- Начальное давление p0: 101325 Па
- Температура T: 288 К
- Молярная масса воздуха M: 0.029 кг/моль
- Газовая постоянная R: 8.314 Дж/(моль·К)
- Ускорение свободного падения g: 9.81 м/с²

Первый диапазон:
- Количество высот: 5
- Начальная высота: 0 м
- Шаг: 100 м

Второй диапазон:
- Количество высот: 4
- Начальная высота: 900 м
- Шаг: 500 м

Физические параметры, количество высот и начальные значения высоты вводятся с клавиатуры. Шаги задаются в программе через именованные переменные.

## Ожидаемые результаты

Программа выводит таблицу значений высоты, атмосферного давления и плотности воздуха.

Первый диапазон высот: 0, 100, 200, 300, 400 м.

Второй диапазон высот: 900, 1400, 1900, 2400 м.

Примеры результатов:

- При h = 0 м: p = 101325 Па, ρ ≈ 1.22719 кг/м³.
- При h = 400 м: p ≈ 96622.1 Па, ρ ≈ 1.17023 кг/м³.
- При h = 900 м: p ≈ 91049.3 Па, ρ ≈ 1.10274 кг/м³.
- При h = 2400 м: p ≈ 76186.3 Па, ρ ≈ 0.922725 кг/м³.

## Запуск программы

1. Открыть файл решения `.sln` или `.slnx` в Visual Studio.
2. Собрать проект.
3. Запустить программу сочетанием `Ctrl + F5`.
4. Ввести физические параметры и количество высот для обоих циклов.
5. Ввести начальную высоту первого диапазона и получить результаты.
6. Ввести начальную высоту второго диапазона и получить оставшиеся результаты.
